# App de Viagens

Projeto simples em React Native com Expo para o exercício 2.

O aplicativo apresenta:
- Tela inicial com logo;
- Tela de destinos;
- Tela de detalhes;
- Navegação entre as telas.

O aplicativo é apenas visual e não possui banco de dados ou compra de viagens.

## Executar

```bash
npm install
npx expo start
```
